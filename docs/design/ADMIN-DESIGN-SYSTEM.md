# Admin Design System

The admin UI prioritizes information hierarchy, dense but readable data, predictable forms, visible system state, and safe decisions. Reuse shared brand tokens selectively; operational clarity outranks decorative continuity with the public site.

Primitive requirements include buttons, links, inputs, text areas, selects, date/time controls, rich editor boundary, tables, pagination, filters, badges, notices, toasts, dialogs, drawers, tabs, uploads, breadcrumbs, validation summaries, skeletons, empty states, and error recovery.
